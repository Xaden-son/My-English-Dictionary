# My English Vocabulary Collection

I started keeping these vocabulary lists in 2024, before I began English preparatory school.

I have been actively expanding them ever since by adding new words, meanings, example sentences, expressions, and phrasal verbs that I encounter while studying English.

A large portion of the vocabulary in this repository can be found in major English proficiency exams, academic reading passages, university materials, and other formal English texts.

I decided to make this repository public so that other learners can also benefit from it. If you are preparing for an English exam or simply looking for a vocabulary resource, these lists may be useful to you.

This is an ongoing collection and will continue to receive new vocabulary over time.
